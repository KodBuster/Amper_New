# АМПЕР A v14.2 — исправленный Hero

База: утверждённый АМПЕР A v14.1. Версия предназначена для демонстрации проекта заказчику.

## Открыть

- `AMPER-A-V14.2-STANDALONE.html` — автономный сайт, изображения встроены в файл.
- `AMPER-A-V14.2.html` — облегчённый HTML; открывать рядом с папкой `assets/`.
- `index.html` — стартовая страница.

## Исправлено по скриншотам

1. Удалены декоративные чёрные полосы по нижнему краю Hero.
2. Удалена длинная строка «Быстрый переход», которая заходила на фотографию и уже дублировала навигацию сайта.
3. Удалена маленькая текстовая наклейка на фотографии.
4. Исходная предметная фотография перекомпонована на едином жёлтом фоне без добавления выдуманных товаров. Созданы 2 кадрирования: desktop и mobile/tablet.
5. Адаптивность: двухколоночный Hero от 821 px; на меньшей ширине — вертикальная компоновка. Увеличена видимая высота фотографии на смартфонах.
6. Исправлено сжатие поиска на ширинах 701–960 px. При 320 px устранено переполнение быстрых карточек следующего раздела.
7. Обновлена демо-маркировка до 14.2.

## Проверено

- Chromium: 320, 390, 701, 768, 869, 900, 1024, 1440 px.
- В проверенных экранах отсутствуют горизонтальное переполнение, ошибки JavaScript, чёрные полосы в Hero и пересекающие изображение ссылки.
- Кнопки «Перейти в каталог» и «Купить по списку» открывают ожидаемые деморазделы.
- Автономный HTML проверен на 390 px.

Все товары, цены и юридические документы остаются демонстрационными. Полный аудит всех внутренних страниц в этой итерации не проводился.
